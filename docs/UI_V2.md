# NEXUS LAB UI/UX V2 实施说明

## 视觉与体验方向

延续白色卡片、浅薄荷背景、深绿主操作、圆角与留白。以统一线性 SVG 图标、清楚的字号层级、轻边框/阴影与克制的悬停反馈提升一致性。不引入图表库、动画框架、外部字体、编辑器或额外运行时依赖。

## 本轮模块

1. 十学院使用同一概览、目标、分级课程与实践页面。首次引导覆盖十个方向，不默认指定学院。目录支持搜索与真实可用内容筛选；发布状态和学习完成状态分别显示。
2. 首页根据已选择方向、已有进度与本轮新增的本机访问记录续学。没有历史时提供中立起点；不显示假数据、连续学习天数或成就。始终提供全部学院入口。
3. 作品页读取原有工作表/实验/Python 证据，展示实际成果、详情和用户主动导出；模板链接到真实练习。没有证据时使用诚实空状态。
4. 共享面板组件支持桌面并列与手机标签切换，保留挂载状态。课时逐步呈现学习、练习、反馈；实验分任务、操作和结果。Python 继续真实执行并按需加载。
5. Mentor 使用紧凑展开面板与四种教学模式，保持平台 AI / 非生成式帮助来源标签及静态部署限制。保留服务端密钥、配额、账户与同步边界。
6. 五项底部导航使用安全区域，正文/操作区预留滚动空间；44px 操作目标、可见焦点、低动画和窄屏防溢出。深色模式为可选项，本轮先完善现有浅色主题。

## 兼容与范围

保留现有路由、内容 ID、localStorage 键、账户同步模式和后端。访问历史使用独立的新键，只记录实际访问，不把访问当成通过。不会清空或迁移旧证据。课程呈现层复用现有内容；完整跨学院课程依赖图和服务端通用进度迁移仍是独立后续工作。本轮不会虚构其他学院的已完成课程。

GitHub Pages 保留 `/nexus-lab/` 与 HashRouter，所有改动同时验证静态版。新学习分支为 `develop/ui-v2`，未经新的推送指令不修改远端 main。

## 验收

lint、typecheck、领域测试、完整浏览器回归、生产构建/冒烟和 Pages 构建/浏览器检查。新增验证覆盖十学院引导、首次/回访首页、旧记录读取、真实作品与导出、移动面板状态保持、360/393px 和桌面溢出/可访问性、Python 真实输出，以及静态部署无 API 请求。


## 实现细节与限制

- `content/experience.ts` 是呈现层目录，复用原始学院 ID 与实验 ID；不是完整课程依赖图。所有学院都有同样的目标、先修说明、三层课程规划与可用实践入口。`content/catalog.ts` 的旧 available 字段保留兼容，新的 UI 以逐项课程/实践状态呈现。
- 旧 v1 进度没有 lastLesson/新访问历史时也能继续下一课；仅有 Python 或其他实验成果时，首页回到实际练习，不显示另一学院的零进度。
- 实验与工作表需有有效通过证据才显示为作品， 格式异常的记录不显示为通过，也不被删除。导出仅包含当前成果，由用户主动下载；不会导出账户凭据或 AI 平台设置。
- `WorkspacePanels` 在手机提供带键盘左右/Home/End 操作的 tabs，桌面同时显示面板；所有内容持续挂载，跨标签不会重置输入、答案或 Python worker。运行/检查给出真实反馈，不提供空的装饰操作。
- 没有新增运行时依赖。完整应用首屏 JS 约 139 KB gzip，CSS 约 8.4 KB gzip；Pyodide 的约 12 MB 资源只有点击加载才请求。Python/公式工作区保留代码分割，不引入重量级编辑器或动画框架。
- 移动验证包含 Pixel 7 Chromium 模拟、360px 窄屏和四倍 CPU 降速，以及安全区域 CSS、44px 点击目标、导航避让和页面防溢出。没有真实 Android 硬件或完整人工屏幕阅读器认证，不声称已完成这些未执行检查。
- 实时生成式 AI 仍未配置/验证。未实现深色主题、通用云作品编辑器、跨学院依赖图与服务端进度新格式；已有后端与真实实验功能保留。
